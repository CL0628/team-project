## User Stories

### MVP User Stories

1. As a player, I want to play with a computer bot so I can play UNO even when I can't find other players.

2. As a player, I want my game play stats and rank to be stored so I can check them later. (this one is for satisfying data storage features…)

3. As a player, there should be a count down timer that displays how much time is left for my turn.

4. As a player, I should be able to declare “UNO” when I only have one card left, so that i do not have to draw a penalty card

5. Implementation: Link “UNO” to some key on the keyboard.

6. As a player I want to declare “UNO” when another player has one card left, so I can prevent the other player from winning

7. As a player, if I have any playable cards, I should be able to play it when it’s my turn, so that I can get rid of cards.
   - Playable cards are:
      - Playing a card that matches the colour (red, blue, green, yellow)
      - Playing a card that matches the number (0-9)
      - Playing a card that matches the symbol or action (wild card, skip, reverse, +2, wild +4 card)
9. As a player, I want to draw a card when I have no playable cards, so that I can continue playing.

10. As a player, I want to know the direction of turns, so that I know who I can add cards to.

11. As a player, I want an indicator of who’s turn it is, so that I can keep track of what is happening in the game

12. As a player, I want to see the winner when a round ends, so that I know the results.

13. As a player, I want to decide the colour of a wild card or wild +4 card when I play one so that other players have to follow through.


### Additional User Story

1. As a player, I want to play with other users online so I can play with my friends.

2. As a player, I want to view the game rules so that I can learn how to play.

3. As a player, I want to be able to draw or upload my avatar, so i can customize my game experience

4. As a player, I want to customize my game lobby music, so I can enjoy music that matches my preferences.

5. As a player, I want to customize my UNO background, so that I can personalize the game's appearance.

6. As a player, I can modify my “uno” audio, so I can customize my game experience.

7. As a player, I can throw eggs and tomatoes to other player avatars, so the game feels more interactive.

8. As a player who has difficulty distinguishing colours, I want cards to display colour labels or symbols so that I can identify them easily.
